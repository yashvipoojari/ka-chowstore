# KA-CHOW! 🚗

**Luxury Diecast Model Car Store**

🌐 **Live Site:** [https://ka-chowstore.netlify.app/](https://ka-chowstore.netlify.app/)

---

## About

KA-CHOW! is a luxury diecast model car e-commerce store built with vanilla HTML, CSS, and JavaScript. Browse and shop premium scale models across 1:12, 1:18, 1:24, and 1:32 scales.

---

## Pages

| Page | Description |
|---|---|
| `index.html` | Home page with hero section and featured scale collections |
| `products.html` | Full collection with search, brand & scale filters |
| `product.html` | Individual product detail view |
| `cart.html` | Shopping cart with quantity controls |
| `checkout.html` | Checkout with Card / UPI / OTP payment flow |
| `login.html` | Login page with Google Firebase Authentication |

---

## Features

- 🔍 Search and filter by brand and scale
- 🛒 Add to cart with localStorage persistence
- 💳 Mock checkout flow (Card, UPI, OTP)
- 🔐 Google Sign-In via Firebase Auth
- 📱 Responsive grid layout
- 🌑 Dark luxury UI theme

---

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Firebase Authentication (Google Sign-In)
- LocalStorage for cart state
- Netlify for deployment
